# 内置指标模块

业务接口为 `CIndicator`。策略不包含 TA-Lib 头文件；`CBootLoader` 独占运行时，初始化成功后才创建策略服务，全部策略和回调停止并销毁后再清理指标库。初始化、清理均可重复调用；同一进程仅允许一个活动所有者。共享锁允许并发计算，初始化及清理持有独占锁，不在运行期间改变 TA-Lib 全局设置。

## 编译与使用

`IndicatorSources.cmake` 和 `IndicatorSources.props` 使用相同源文件清单。上游 `.c` 文件以 C11 编译、禁用隐式浮点乘加收缩；指标封装和策略使用现有 C++20。源码直接参与 `xengine_services` 或 VS 远程 Linux 工程的编译，不下载依赖、不生成单独 TA-Lib 库，也不增加 TA-Lib `.so` 依赖。Linux 需要数学库 `m`。

`CalculateSma` 接收从旧到新的连续 `double` 样本，仅返回最后一个样本位置的 SMA。窗口为 1～100000，周期 1 直接返回最新样本；其他周期调用 `TA_SMA`。未初始化、样本不足、非有限输入、非法周期或库错误均返回 false，填充错误信息并保留调用者原输出。

均线策略按交易所与证券代码隔离状态，使用有界环形窗口及复用的连续缓冲区。价格按 `last_price / 10^price_scale` 归一化，精度范围 0～18；委托保留原始定点价格与精度。它计算的是最近 N 次有效报价的均线，不合成 K 线，也不根据时间重采样。相等容差为 `1e-12 * max(1, abs(short), abs(long))`。

短长窗口默认 5/20，必须满足 `1 <= short < long <= 100000`。服务端在写配置和替换运行时前校验，终端编辑校验同步。首次建立关系不报单；后续按原关系反转逻辑触发限价委托，数量仍为 100。暂停保留历史且不采样，停止清空各证券状态、保留实例信号序列。指标故障按证券抑制重复日志，恢复后可记录下一次故障。
